# v1.3.81 更新公告

本次重写连接逻辑，现在无需部署插件即可直连游戏进程。

## 主要更新

- 增加各账号游戏进程锁帧，用于降低游戏后台渲染开销。
- 增加自动上传游戏内交易船，支持定时检测、立即执行一轮、价格区间及最高价优先。
- 交易船限时禁售物品记录解禁时间，到期前跳过，仓库卡片显示期限。
- 增加自动 Boss 关与南瓜灯峡谷门票检测，按库存与当前地图判断；加入地图跳转安全间隔。
- 增加定时批量开箱、定时全背包存仓，以及按账号独立判断的污染度和仓库负载腐蚀。
- 仓库增加道具图标卡片、缓存报价与不可交易筛选。
- 统计改为掉落概率、掉落记录、珍品记录三个标签页。
- 品质概率跳过灵魂石及被污染的灵魂石；超凡、天界、神圣、宇宙额外保存珍品记录，重复物品叠加数量并显示最近地图与时间。
- 使用黑黄 TBH助手图标，支持关闭至托盘、按账号隐藏窗口及启动和每12小时检测更新。

## 使用提示

先退出助手再覆盖程序，并备份自己的配置、历史、珍品记录和缓存。发布包不包含个人账号与运行数据。直连版无需安装旧 BepInEx、Java 或观星插件。交易船功能仅转入游戏内交易船，不执行 Steam 市场一键出售。

掉落预览当前暂不可用。统计概率为实际记录样本占比，不代表官方掉率；报价为市场参考值。请遵守游戏与平台规则，自动化存在账号及物品操作风险。
