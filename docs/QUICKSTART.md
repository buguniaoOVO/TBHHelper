# TBH助手直连版使用说明

当前版本 v1.3.82，Windows x64。下载地址：
https://github.com/buguniaoOVO/TBHHelper/releases/download/v1.3.82/TBHHelper-v1.3.82-win-x64.zip

## 首次运行

1. 解压至可写文件夹，从 Steam 启动游戏。
2. 运行 TBH助手.exe，进入“账号”，点击连接或重新扫描；本机和 Sandboxie 实例分别连接。
3. 核对各进程显示的用户名，按需要设置锁帧与窗口显示。
4. 在魔方、地图、仓库页配置任务和保护规则，点击“一键开启”。全部关闭会停止助手自动化，游戏继续运行。

## 常用规则

- 开箱：按分钟设置检测周期，按宝箱品种批量开启。
- 存仓：按分钟设置周期，将背包物品存入仓库；空间不足时受游戏规则限制。
- 腐蚀：逐账号读取污染度和仓库占用，满足条件的账号执行；先检查保护品类与圣物品质。
- 地图：设置瘟疫之地难度、层数、周期与跳转安全间隔。Boss 及南瓜灯峡谷运行时按规则避让。
- 交易船：按设置周期检查四个槽位；可选价格区间或最高价优先，也可立即执行一轮。限时禁售物品在解禁前跳过。
- 报价：使用手动查询或约每小时刷新，显示最近一次成功缓存。参考价不保证实际成交。
- 统计：切换掉落概率、掉落记录、珍品记录。灵魂石不计品质概率；四种珍品品质额外保存在本地。
- 更新：启动与每12小时检测 GitHub 发布信息；设置中可关闭自动检测，更新由用户确认。

## 覆盖更新

先正常退出助手，再用新程序覆盖。保留 auto_synthesis_config.json、auto_synthesis_history.jsonl、auto_synthesis_rare_drops.jsonl 和 cache。建议先备份整个旧目录。

当前直连版无需向游戏目录安装插件。旧插件版启动器、Java 脚本和 BepInEx 部署步骤属于历史版本，不用于当前版本。

## 当前限制与反馈

掉落预览暂不可用。游戏更新、网络限流及市场数据源异常可能影响功能。遇到操作异常先点全部关闭，并附版本、复现步骤与脱敏日志反馈：
