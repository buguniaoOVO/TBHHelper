# TBH助手快速上手

## 首次安装

1. 下载 Windows x64 ZIP，完整解压。文件夹里双击 `TBH助手.exe` 即可启动，不需要命令行或额外安装 Java。
2. 先退出游戏并启动助手。助手识别游戏目录后，自动核验并同步当前安装包的 DLL；目录未识别时，在设置页填写目录。缺少环境时会部署附带运行文件，也可以点“一键部署”进行完整校验。
3. 从 Steam 重新启动游戏，等待显示“游戏已连接”。该状态表示助手已收到本地插件 API 的有效响应。首次部署必须重启游戏，BepInEx 才会加载插件并为本机游戏生成 interop 接口程序集。
4. 先检查品质上限、包含仓库和地图目标。腐蚀排除项分别控制铭文卷轴与纪念币；雕刻材料和其他材料会保留。再点“一键开启”。F8 或“全部关闭”停止总任务。
5. 在设置页切换中文 / English，并选择关闭按钮的默认行为。
6. 助手启动后及每隔 6 小时自动检测 GitHub 版本。发现新版本时，点击顶部更新入口确认下载；也可以在设置页点“检测更新”，或点“打开发布页”查看说明与下载。

## 防掉线与一键开启

设置页的“启用防掉线”按分钟检查游戏与插件连接，异常时结束游戏进程并通过 Steam 重新启动，设置页显示重启次数和最近状态。该功能默认关闭；开启后助手启动时会尝试获取管理员权限，被拒绝时以普通权限运行并用红字提示。

点击“一键开启”后，助手先立即执行一轮地图检测、腐蚀、仓库整理和开箱，再转入按 CD 的定时调度。未启用的功能会自动跳过。

首页底部“免责说明”提供官方发布页、QQ群和赞助链接；上方链接栏配有 GitHub、聊天框和爱心图标。本助手免费下载和使用；Awan维护代码在 GitHub 开源。官方群号为 123777707，验证答案为“挂机助手”。赞助完全自愿。

## 文件

| 文件 | 作用 |
| --- | --- |
| `TBH助手.exe` | 启动入口，双击即可运行，任务管理器显示 TBH助手 |
| `runtime` | 内置 Java 运行库，随包提供 |
| `TBH-Helper-v1.3.61.jar` | 助手界面与逻辑 |
| `TBHPlugin-自动腐蚀版.dll` | 游戏插件，一键部署时复制到游戏的 `BepInEx/plugins/TBHPlugin.dll` |
| `BepInExPackage` | 官方 IL2CPP 后台运行环境，一键部署时释放 |
| `settings.properties` | 你的助手配置 |
| `game-path.txt` | 助手记住的游戏目录 |

## 更新

退出游戏和助手，再解压新版。保留自己的 `settings.properties`、`game-path.txt`、`activity.tsv`、`stats.properties` 与缓存；替换程序、插件和运行文件。已加载的 DLL 需要在游戏关闭后替换，也可以直接对新的 `TBH助手.exe` 再点一次“一键部署”。

## 暂停与停用

F8 暂停自动任务；退出助手停止桌面任务。关闭按钮默认缩小至托盘，可在设置里改为每次询问或直接退出。清除插件环境时，先退出游戏，在设置页填写或浏览到含 `TaskBarHero.exe` 的游戏目录，点“验证并保存”，再点“清除完整环境”。清除会永久删除完整 BepInEx 环境、所有 BepInEx 插件和配置以及随环境部署的根目录启动文件，不创建备份；此操作也会停用其他 BepInEx 插件。

## 排查连接

确认游戏已经进入角色，助手显示“游戏已连接”，并且游戏的 `BepInEx/LogOutput.log` 包含 `TBH Auto API 1.3.61` 与实际监听地址。连接前会核验当前游戏进程、插件协议和 DLL 哈希。

助手概览与设置页显示实际接口地址。插件先尝试本机端口 19090，被占用时自动选择其他可用端口。助手按游戏进程的发现记录读取地址，并核验进程与实例标识。

出现连接失败时，查看助手的 DLL 初始化状态和游戏日志。助手会随游戏启动重新发现地址；游戏加载旧 DLL 时需要退出游戏，等待自动同步完成后再启动。

首次部署遇到权限错误时，将助手解压到可写目录，并确认 Steam 游戏目录可以写入。游戏目录已有其他 `winhttp.dll` 时，一键部署会先备份被覆盖的文件再写入。

运行中遇到拒绝或结果未知时，先暂停并等待本次请求结算，再处理游戏连接。腐蚀间隔可设 10～120 秒，统一操作间隔默认 20 秒。

普通宝箱和稀有/BOSS 宝箱从开启自动任务时按各自 CD 定时检查，普通与污染变体分别通过游戏右键入口批量开启。每步点击间隔默认 5 秒；全任务共用间隔默认 20 秒、最低 3 秒。到期任务与正在执行的操作冲突时排队，概览显示排队倒计时；待命时显示计划时刻。

助手以当前安装包的 DLL 为准。游戏正在运行且 DLL 不一致时，助手等待游戏退出后自动同步；只有实际加载的 DLL 和接口实例均通过校验，才会显示已连接。

顶部连接区在初始化与同步期间显示黄色提示。DLL 就绪后显示“初始化完成”，等待游戏连接；连接成功时隐藏初始化提示。提示的鼠标悬停说明中包含具体进度或失败原因。

自动更新通过后台线程检查 GitHub 最新发布。每次启动与每隔 6 小时检查一次，同一新版本在本次运行中提醒一次；下载和替换需要点击确认。设置页显示最近检查状态，连接 GitHub 失败时保留当前程序继续运行。

更新与版本迭代都保存在同一个安装目录，一般在 `D:/Tool/赛博养蛊/` 下按版本号建立新目录。替换前会备份 `settings.properties`、`stats.properties`、`activity.tsv`、`game-path.txt`、`cache` 和 `旧版文件`，覆盖程序后自动恢复，设置、掉落与统计记录继续沿用。
