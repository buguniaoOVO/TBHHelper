# TBH助手直连版更新与使用介绍

大家好，我是阿丸AWan。这次更新了 TBH助手 v1.3.82，给 TaskBarHero 的日常托管加入了直连、多账号窗口控制、游戏进程锁帧、自动交易船，以及 Boss 和南瓜灯峡谷的门票检测。下面按页面介绍功能和用法。

这一版重写了连接逻辑，通过 Frida 直接连接已经运行的游戏进程，无需向游戏目录部署插件。本机和 Sandboxie 多开实例分别连接，账号页会显示对应用户名，便于核对操作对象。

![账号页可分别连接本机与沙盒进程 用户名已打码](images/02-accounts-redacted.png)

运行环境为 Windows 10/11 x64。下载压缩包后完整解压，从 Steam 启动游戏，再运行 TBH助手.exe，在账号页点击连接或重新扫描。建议先核对账号，检查各页规则，再点击一键开启；全部关闭可停止助手自动化。

每个账号可以单独隐藏或显示游戏窗口，也可以单独设置锁帧。锁帧用于降低后台渲染开销，实际占用取决于机器和游戏场景。关闭助手窗口可缩到托盘，需要退出时使用退出助手。

## 定时开箱 自动存仓与腐蚀规则

后台任务按各自的检测时间运行。自动开箱按设定的分钟数检查宝箱，默认每分钟检测一次；开启时按宝箱品种批量处理，一种完成后再处理下一种，操作之间保留安全间隔。

自动存仓按设置的分钟数执行，将背包物品存入仓库。实际可存入数量受仓库剩余空间和游戏规则限制。合成仍可按已有的装备、材料规则设置。

![腐蚀页可配置污染度 仓库占用与物品保护规则](images/04-corrosion.png)

自动腐蚀的污染度和仓库占用按账号独立读取。某个账号污染度低于设定值，或仓库占用达到设定比例时，由这个账号执行腐蚀，其他账号继续按自己的条件判断。

腐蚀前请检查保护规则。灵魂石、供奉材料、杰克入场券都可以保护，圣物可按品质设置保护。开箱、合成、腐蚀等提交操作使用安全间隔；道具操作会实际消耗物品，请先用少量物品核对配置。

## 瘟疫之地 Boss与南瓜灯峡谷

瘟疫之地可以设置难度、1至20层和检测间隔。助手读取当前地图，符合跳转条件时前往目标地图；处于 Boss 关或南瓜灯峡谷时按规则避让。地图跳转之间还可以设置以秒为单位的安全间隔。

Boss 和南瓜灯峡谷分别设置门票数量要求，按分钟周期检查库存和当前地图。达到要求且当前不在相关挑战地图时，再进入对应关卡。

![地图页统一设置目标地图 检测周期与跳转安全间隔](images/05-map.png)

这里的 Boss 关包括被污染的指挥室和3-10，南瓜灯峡谷作为单独的活动挑战处理。进入 Boss 后，持续战斗和门票消耗由游戏推进，助手依据后续检测结果决定下一轮操作。

使用前请核对目标难度、层数、门票阈值和检测时间。游戏更新可能改变地图或进程接口；若出现画面与地图状态不一致、传送门等待异常等情况，先点全部关闭，再提供版本与复现步骤反馈。

## 仓库图片卡片与自动交易船

仓库页可以查看不同账号的物品，并按名称、品质、类型和价格等条件筛选或排序。相同物品合并数量，永久不可交易的物品从展示中隐藏。报价支持手动查询，也会约每小时后台刷新；正常刷新成功前使用上一次缓存。

自动交易船支持设置检测间隔，可选择价格区间或最高价优先，也能点击立即转入一轮。每轮检查四个槽位，按规则选择物品，完成放入和确认上传流程。

![仓库以白底图片卡片显示道具 并标示品质 数量与缓存报价](images/06-warehouse.png)

遇到暂时无法出售的商品，助手记录游戏给出的可出售时间，在该时间前跳过，并在仓库卡片上展示解禁日期。成功上传后，槽位按游戏规则进入冷却；后续检测到空位时继续处理。

这里的交易船指游戏内交易船，功能范围是转入和确认上传。Steam 市场一键出售和导入账号工具已移除。报价是市场参考值，限流、网络和数据源变化可能影响查询结果，参考价不能保证实际成交。

## 掉落概率 明细与珍品记录

统计页上方保留近24小时宝箱数和累计宝箱数，下方通过三个标签页切换。掉落概率按各品质有效掉落数量除以有效掉落总数计算，灵魂石及被污染的灵魂石从分子和分母中排除；装备、首饰、材料合成产物不进入掉落统计。

掉落记录保留灵魂石明细，详情表只展示品质、物品、数量、最近地图和最近掉落时间。珍品记录额外保存超凡、天界、神圣、宇宙品质掉落，相同物品累计数量，显示最近掉落时间与地图，并在助手重启后恢复。

![统计页使用掉落概率 掉落记录 珍品记录三个可切换标签页](images/07-statistics.png)

概率是已记录样本占比，不代表官方掉率。掉落预览暂不可用。设置支持启动及每12小时检测更新，可关闭自动检测，更新需用户确认。

更新前请退出助手并备份旧目录，保留配置、历史、珍品记录和缓存。请遵守游戏及平台规则，自动化存在账号和物品操作风险。反馈时附版本、复现步骤和脱敏日志。
