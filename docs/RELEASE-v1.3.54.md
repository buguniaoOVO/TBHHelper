# TBH助手 v1.3.54 · 排队界面与部署问题说明

## 本地测试改动

- 概览自动化卡使用紧凑状态，长队列详情放入鼠标提示，避免撑宽相邻卡片。
- 全任务共用间隔可设 3～300 秒，默认 20 秒。
- 腐蚀排除项只识别铭文卷轴，不排除其他材料类型和装备。
- 开箱按 `StageBox` 游戏对象的 `EBoxType` 分类：普通宝箱由普通箱任务开启，BOSS 与章节 BOSS 由蓝箱任务开启；污染 `EContentType.PLAGUE` 不改变分类。保留界面对象名作为兼容回退。

## 其他先前请求

- 每步点击间隔可设 1～300 秒，默认 5 秒；多个队列任务从完整任务及动画结束后计时。
- 游戏助手日志每行带有记录时间。

本包仅作 x64 本地测试。编译和发布包结构审计通过；未在实际游戏中执行腐蚀或宝箱操作，未同步 GitHub。
