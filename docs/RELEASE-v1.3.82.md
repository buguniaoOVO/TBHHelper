# v1.3.82 窗口响应修复

本次修复 v1.3.81 出现的界面重绘回归，建议旧版用户更新。

- 移除统计标签页整块区域使用的极小图片平铺，减少窗口缩放与导航时的重绘。
- 导航只布局当前页面；窗口改变大小时保持 DPI 字体清晰，并调整顶部工具栏排列。
- 统计合并连续掉落刷新请求，历史未变化时复用结果，缓存物品信息。
- 游戏窗口隐藏与恢复改为异步请求，逐账号独立确认；一个窗口超时不再串行等待，保留重试入口。
- 退出时直接投递恢复请求，避免在退出清理前等待游戏窗口响应。
- 掉落记录移除概率列，只显示品质、物品、数量、最近地图、最近掉落时间；品质概率汇总页保留。

## 验证与范围

本地完成62项单元与回归测试、72次导航切换、20次窗口尺寸变化，以及跨进程无响应窗口与正常窗口并行处理测试。模拟无响应窗口请求约3毫秒返回，正常窗口继续完成隐藏和恢复。测试没有操作游戏道具，也未关闭游戏进程。

游戏本体卡死目前尚未复现；本版本修复已确认的助手重绘及窗口调用连带阻塞，仍需持续观察实际游戏运行。

先退出助手再覆盖程序，保留个人配置、历史、珍品记录和缓存。压缩包不包含个人数据，继续使用无插件连接模式。掉落预览暂不可用。
