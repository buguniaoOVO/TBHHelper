# TBH助手 v1.3.59 · DLL 自动同步与更新提醒

本次公开发布汇总 v1.3.49～v1.3.59 的改动。助手和游戏插件均为 1.3.59，支持 Windows 10/11 x64、Steam 版 TaskBarHero。

## 初始化与连接

- 启动时核验游戏目录，并自动同步当前安装包的 DLL；游戏正在使用旧 DLL 时，等待游戏退出后同步。
- 顶部连接区在初始化与同步期间显示黄色提示。DLL 就绪后等待连接，通过校验后显示“游戏已连接”，并隐藏初始化提示。
- 连接前核验 DLL 版本、SHA256、协议、游戏进程与接口实例。
- 插件自动选择本机可用端口，默认 19090 被占用时更换；助手跟随实际接口地址，概览和设置页显示地址。

## 自动更新

- 启动后检测 GitHub 最新发布，随后每隔 6 小时检测一次。
- 有新版本时显示顶部更新入口并发送托盘消息，同一版本在本次运行中提醒一次。
- 点击确认后下载完整包，在助手退出后替换程序并自动重启；个人设置、游戏目录、统计和缓存保留。
- 设置页提供手动检测、发布页入口和最近检测状态；自动检测失败记录到运行日志。
- 修复更新替换时误删新版 JAR 的问题，校验安装目录和临时清理路径。

## 腐蚀、开箱与任务节奏

- 铭文卷轴和纪念币分别设置排除。雕刻材料与其他符合品质规则的物品继续参与腐蚀，剔除后剩余 1～9 件均按腐蚀流程提交。
- 装备和材料依次填充空位，执行前刷新品质映射，并记录逐件排除原因。
- 自动腐蚀间隔为 10～120 秒，由右下角“确认并应用设置”统一保存。
- 普通、稀有、BOSS 和污染变体通过游戏原生右键入口批量开启，按各自 CD 检查。
- 到期任务遇到操作冲突时排队。概览显示当前任务、下一项任务、计划时间和实际排队倒计时；队列详情放在鼠标提示中。
- 点击间隔默认 5 秒，全任务共用间隔默认 20 秒、最低 3 秒；运行日志逐行显示时间。

## 仓库与部署

- 市场报价可以独立刷新，报价请求失败时显示原因，并保留已有价格供查看。
- 设置页支持手动填写、浏览和验证游戏目录。
- 一键部署逐项校验 `winhttp.dll`、`BepInEx/core/BepInEx.Unity.IL2CPP.dll`、`dotnet/coreclr.dll`、插件 DLL 和 Doorstop 配置。
- 检查 `doorstop_config.ini` 的 `target_assembly` 与 `coreclr_path` 是否指向随包文件。
- “清除完整环境”永久移除游戏目录中的 BepInEx 环境、所有插件、配置和生成文件，清除过程不创建备份。此操作需要先退出游戏。

## 安装与更新

1. 下载 **TBHHelper-v1.3.59-win-x64.zip** 并完整解压，双击文件夹里的 **TBH助手.exe**。
2. **先退出游戏**，在设置页确认游戏目录。助手会自动初始化 DLL，也可以点击“一键部署”进行完整环境校验。
3. **从 Steam 重启游戏**，首次启动等待 BepInEx 生成接口文件。助手显示“游戏已连接”后，检查品质、仓库范围和排除项，再开启任务。
4. F8 或“全部关闭”停止自动任务。旧版用户保留自己的设置、游戏目录、统计和缓存，启动新版后等待 DLL 同步，随后重启游戏。

完整包附带 Java 运行库与官方 BepInEx IL2CPP 环境。合成、腐蚀和自动前往地图默认关闭；铭文卷轴与纪念币排除默认开启。

Clash/TUN 分流由各电脑的代理软件管理。游戏登录需要正常的 DNS 和服务器连接，助手 API 使用本机回环地址。

## 附件与核对范围

- **win-x64.zip**：完整程序、运行库、游戏插件、部署环境及使用说明。
- **forum-kit.zip**：论坛介绍正文和配图。
- **SHA256SUMS.txt**：下载文件校验值。

发布包经过编译和文件审计，完整部署环境与官方来源逐项对照。跨电脑首次使用仍需查看游戏插件日志；本次发布没有在其他玩家电脑上实测游戏内操作。
