# TBH助手 v1.3.48 · 连接状态与部署校验

## 修订内容

- 顶部与概览页的连接状态现在以 `127.0.0.1:19090` 插件 API 的有效响应为准。游戏窗口存在但 API 拒绝连接时显示“插件未连接”。
- 一键部署后核对 `winhttp.dll`、`doorstop_config.ini`、BepInEx 核心 DLL 与游戏插件的完整性；文件缺失、写入不完整或权限拒绝时显示明确错误。
- 快速上手和发布说明补充 `Connection refused: getsockopt` 的解释与日志检查路径。

## 使用

Windows 10/11 x64。完整解压 ZIP，双击 `TBH助手.exe`；首次使用时退出游戏，在设置页点“一键部署”，随后从 Steam 重启游戏。启动后等助手显示“游戏已连接”再开启自动任务。

游戏已打开但助手显示“插件未连接”时，查看游戏目录 `BepInEx/LogOutput.log`。插件成功启动时会记录 `TBH Auto API` 和 `监听中: http://127.0.0.1:19090/api/`。若助手日志显示 `Connection refused: getsockopt`，当时该本地端口没有插件服务监听。
