# TBH助手 v1.3.85 · 2026-10-27 游戏更新适配

游戏已于 2026-10-27 更新（Steam 构建 26211490）。旧版依赖的方法名、字段偏移和调用地址失效，表现为地图跳转、开箱、仓库读取和统计异常。本版按新版 `GameAssembly.dll` 重新适配，继续使用无插件直连，不向游戏目录安装任何插件。

## 本次适配

- 地图与传送门、Boss 及南瓜灯峡谷、门票挑战入口。
- 开箱（按宝箱品种批量开启）、存仓、背包与仓库读取。
- 魔方合成、腐蚀、自动交易船及 Unity 界面入口。
- 关卡缓存、污染度控制器、合成配方与掉落日志字段。
- 仓库界面当前页字段更新至 `0xe8`（旧 `0xc8` 在新版为滑动开关引用）。
- 更新原生开箱入口及结果监听，保留请求安全间隔。
- 保留未知版本阻断，并增加元数据与地址锚点校验。

## 验证

本机与两个 Sandboxie 实例共 3 个游戏进程，完成相同的 17 项接口准备与只读检查：版本、库存、仓库、合成接口、合成 UI、九档配方、存仓、整包存仓、开箱、地图、南瓜关、污染度/腐蚀、交易船、帧率读取、统计日志、监听器和 Unity 主线程队列。三组全部通过，监听器设置错误为空。

检查期间没有发送开箱、合成、腐蚀、存仓、上架、门票消费或地图切换请求；三个游戏进程检查后仍存活。接口准备通过不等同于服务器操作实测。

在线报价列表与汇率源的单次连接检查发生 TLS 握手超时，本版未验证在线报价刷新；既有缓存与回退逻辑保持原状。

## 自 v1.3.82 起的累积更新

- 账号卡片逐进程显示当前地图、交易船槽位总数、占用数量与逐槽冷却；每 15 秒只读刷新。
- 统计页改为“掉落概率 / 掉落记录 / 珍品记录”三个标签页；品质概率排除灵魂石。
- 超凡、天界、神圣、宇宙掉落额外写入珍品记录，相同物品叠加数量并显示最近时间与地图。
- 仓库图标卡片、报价缓存与交易限时禁售时间展示。
- 修复统计页背景平铺造成的重绘卡顿；窗口隐藏与恢复改为异步，按账号独立确认。

## 升级方式

先正常退出助手，再用本包中的 `TBH助手.exe` 覆盖旧程序。保留 `auto_synthesis_config.json`、`auto_synthesis_history.jsonl`、`auto_synthesis_rare_drops.jsonl` 与 `cache`。建议先备份整个旧目录。

压缩包不包含个人配置、账号缓存与运行日志。掉落预览当前暂不可用。
