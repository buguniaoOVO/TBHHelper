# TBH助手 v1.3.61 · 防掉线与立即执行

## 防掉线（可选）

设置页新增“启用防掉线”开关和检测间隔（分钟，1～180，默认 10）。开启后，助手按设定间隔检查游戏窗口与插件连接：

- 两者都正常：记录状态，继续等待下一次检查。
- 游戏未运行或插件连接异常：结束游戏进程，等待 8 秒，再用 `steam://rungameid/3678970` 重新启动游戏，之后等待游戏窗口出现。设置页显示重启次数和最近状态。

防掉线默认关闭。只有开启该功能后，助手启动时才会尝试获取管理员权限，避免没有使用该功能的用户反复看到权限提示。

## 管理员权限提示

启动器在启用防掉线时会尝试以管理员身份重新启动自己。用户在提示中拒绝时，助手继续以普通权限运行，设置页用红字说明：游戏以管理员身份运行时，防掉线可能无法结束游戏进程，可右键以管理员身份运行助手。提权成功时显示普通说明。

## 一键开启后立即执行一轮

点击“一键开启”后，助手会先按顺序跑一轮立即执行，再进入定时调度：

1. 地图检测：读取当前地图，不在瘟疫之地时按设置请求前往。
2. 腐蚀：在启用且数据就绪时立即尝试一轮，不受批次间隔和阈值限制。
3. 仓库整理：忽略冷却直接整理一次。
4. 开箱：立即开启一轮普通与稀有/BOSS 宝箱，不受 CD 限制。

每步之间按设置页的共用间隔等待，概览显示当前步骤。地图检测、腐蚀、合成等开关关闭时对应步骤自动跳过。

## 使用

1. 在设置页按需开启防掉线并设置检测间隔；需要时右键以管理员身份运行助手。
2. 游戏已连接后点“一键开启”，会立即执行一轮，之后按各任务 CD 定时运行。
3. F8 或“全部关闭”停止自动任务；防掉线看门狗随助手运行，独立于自动任务开关。

防掉线通过 Steam 重新启动游戏；若 Steam 未运行或协议未注册，会退回直接运行游戏目录中的 `TaskBarHero.exe`。

## 数据保留

版本迭代和自动更新都在同一个安装目录内进行，一般在 `D:/Tool/赛博养蛊/` 下按版本号建立新目录。更新只替换程序、插件、运行文件和文档，替换前先把用户数据备份到安装目录内的临时位置，覆盖完成后恢复并清理备份。保留内容包括 `settings.properties`、`stats.properties`、`activity.tsv`、`game-path.txt`、`launcher-error.log`、`update-error.log`、`admin-status.txt`，以及 `cache` 和 `旧版文件` 目录。设置、掉落与统计记录、缓存会继续沿用。

助手与插件版本：1.3.61。支持 Windows x64。
