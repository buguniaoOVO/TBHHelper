# TBH助手 v1.3.45 · exe 入口与一键部署

助手版本 1.3.45，游戏插件 1.3.43，Windows x64。

- 发布包改为根目录 `TBH助手.exe` 直接启动，双击即用，不再依赖 .cmd 和外部 Java。
- 运行环境随包提供；一次一键部署即可写好后端环境与插件，被覆盖文件先备份到 `TBH-Backups`。
- 启动入口不再读取或改写游戏插件，游戏运行时也能正常打开助手界面。

- 设置页可切换简体中文与英文界面，选择后立即保存。导航“设置/setting”和语言选项保持中英双语。
- 关闭按钮可选每次询问、直接退出或缩小至托盘，默认缩小至托盘，避免反复弹窗。

- 后台开箱、仓库整理、装备 / 材料合成，瘟疫之地与腐蚀配置。
- 铭文 / 铭刻材料逐件剔除，保留其他合格物品；腐蚀允许 1～9 件，执行前校验游戏状态。
- 2 秒界面动作间隔、默认 20 秒统一提交间隔、至少 120 秒腐蚀批次间隔。
- 仓库图片列表、重复合并、筛选排序，TBHIndex Steam 参考报价与人民币估值。
- 三类宝箱、掉落与品质分布、记录保留设置、重复出货合并。
- 纯白界面、游戏风格线条导航、狗狗拉弓图标、托盘关闭选择与独立进程名。
- 公开包增加 Steam 目录检测与手动选择，打包干净运行环境和默认配置。

## 使用

完整解压后双击 `TBH助手.exe`，在设置页点“一键部署”，再从 Steam 启动游戏并等待已连接。配置规则后点“一键开启”，F8 停止。

新包合成、腐蚀、自动前往地图默认关闭。更新请保留自己的配置与统计文件。沿用旧版配置时，界面语言第一次按配置文件读取，默认中文。详细步骤见仓库快速上手。
