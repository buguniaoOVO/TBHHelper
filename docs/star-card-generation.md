# Star 卡片生成说明

使用内置 imagegen，编辑参考为本项目的狗狗拉弓图。成品保存为 `docs/star-support.png`，README 页首与发电图并排展示。

提示词：

> 把提供的透明狗狗拉弓图改成一张 GitHub README 使用的点 Star 支持卡片。保留这只狗狗的脸、搞怪眼神、金黄色皮毛、持弓射箭的姿势和现有清晰卡通线稿画风。制作竖版约 3:4 的完整卡片，白色圆角主区域、浅金色与少量青绿色边框，干净清爽。上方留白，清晰排版准确文字：第一行「给 TBH助手」，第二行大字「点个 Star」。中间放狗狗弓箭形象，搭配一颗金色五角星；下方一个大而圆润的金色 Star 按钮示意，按钮文字「Star」，按钮下面小字「感谢你的支持」。页脚准确写「by Awan」。所有字都清晰正确，无额外文字，无二维码，无鱼，无 PCFish 字样。成品用于与已有发电卡片并排展示，整体为白底、金色点缀的亲切卡通海报。背景是不透明的白色。
