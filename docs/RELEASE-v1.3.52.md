# TBH助手 v1.3.52 · 腐蚀筛选与任务排队

## 改动

- 腐蚀排除项仅识别游戏分类为 `ENGRAVING` 的材料和明确的铭文卷轴名称。通用“铭文/铭刻”字样不再单独触发排除，且排除不看品质。
- 新增可调点击间隔，默认 5 秒；游戏插件收到相同配置，腐蚀清理、魔方操作和其他 API 点击按该间隔节流。
- 自动任务改为 FIFO 队列：宝箱颜色、仓库整理、装备/材料合成、地图切换和腐蚀分别入队。任务完成和动画稳定后开始全局共用间隔，再执行下一项。蓝箱与普通箱分开排队。
- 概览显示执行项、下次执行倒计时；多个任务积压时提示高频风险冲突和排队数量。
- 助手日志每行显示时间，历史日志按记录时间显示。

## 构建

助手 v1.3.52 x64、插件 v1.3.44。发布包结构审计通过。未对运行中的游戏进行腐蚀或开箱实机操作；本版待用户测试后再同步 GitHub。
