# TBH助手 v1.3.50 · 清理路径校验与彻底卸载

## 目录未确认的原因

v1.3.49 的卸载流程只读取 `settings.properties` 中保存的 `game_path`，不会沿用部署时的 Steam 库自动检测或目录选择。发布包使用空白默认配置 `game_path=`；若此前没保存游戏路径，程序把空路径解析为助手当前目录，再因其中没有 `TaskBarHero.exe` 报“游戏目录未确认”。

## 本地测试包改动

- 设置页加入可手动填写的游戏目录栏、浏览按钮和“验证并保存”按钮。路径验证要求目录中有 `TaskBarHero.exe`；支持粘贴带引号的 Windows 路径。
- 清除前再次校验用户指定目录，并保存到 `settings.properties`。错误会指出路径为空或未找到 `TaskBarHero.exe`。
- “清除完整环境”永久删除随 `BepInExPackage` 部署到游戏根目录的文件与文件夹，包括整个 BepInEx 目录（插件、配置、日志、interop）、dotnet 运行时和加载器文件。不创建备份；其他 BepInEx 插件也会被删除。

## 验证范围与发布

Windows x64 本地测试包。进行源码编译和发布包结构审计；没有对当前游戏安装目录执行永久删除。按既有发布约定，本版先交付测试，确认无误后再同步 GitHub。
