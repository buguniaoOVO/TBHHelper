# 直连版维护快照

本目录保存 v1.3.82 使用的界面替换脚本、Frida 连接脚本和 PyInstaller 归档补丁工具。运行与 marshal 字节码相关的构建必须使用 Python 3.14。

补丁流程依赖指定的旧归档基线、物品字典、图标与 rcedit；此目录未包含完整初始工程和全部构建输入，不提供从零构建承诺。不能反复以已经包装过 main 的新 EXE 作为基线，否则会嵌套入口包装。

PE 图标修改应只作用于 bootloader stub，再拼回原归档 overlay，并验证归档条目及脚本哈希。当前成品请从 Releases 下载。

历史 Java 与 BepInEx 代码继续保留在原目录，与当前直连发行版分开维护。个人配置、账号信息、历史记录、价格缓存和运行日志不属于维护快照。
