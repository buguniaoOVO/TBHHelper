# TBH助手 · by Awan

TaskBarHero 的 Windows 桌面助手。提供后台开箱、仓库整理、自动合成、瘟疫之地与腐蚀设置，以及带道具图片和市场参考价的仓库页面。

**[下载 v1.3.63](https://github.com/buguniaoOVO/TBHHelper/releases/tag/v1.3.63)** · [快速上手](docs/QUICKSTART.md) · [论坛介绍帖与配图](docs/forum-post.md) · [问题反馈](https://github.com/buguniaoOVO/TBHHelper/issues)

![运行概览](docs/images/01-overview.png)

## 功能

| 页面 | 功能 |
| --- | --- |
| 概览 | 游戏连接、任务状态、模块入口；一键开启、全部关闭、F8 停止 |
| 合成 | 装备与材料分别启用，设置最高品质、包含仓库、等级和间隔 |
| 瘟疫之地 | 检测当前地图，设置强度 1～20、检查间隔，以及自动腐蚀规则 |
| 仓库 | 读取储物箱道具，图片展示、重复合并、搜索筛选、价格排序与参考估值 |
| 统计 | 普通、稀有、BOSS 三类宝箱；掉落记录、品质数量与比例、出货合并 |
| 日志 / 设置 | 运行记录、保留时间、连接与运行环境配置 |

### 界面语言与关闭方式

设置页可以选择简体中文或英文界面，选择后立即保存；导航中的“设置/setting”和语言选项标为双语，方便在两种语言下找到。道具名称和游戏原始日志保持游戏自身的语言。

关闭按钮支持三种默认行为：每次询问、直接退出、缩小至托盘。默认缩小至托盘，自动任务继续运行，点击托盘图标恢复窗口。

### 后台动作与操作节奏

助手通过本机接口调用游戏内部的按钮和动作入口，自动库存任务使用后台 API 流程。插件在本机 `127.0.0.1` 自动选择可用端口，并发布实际接口地址；桌面程序负责显示、配置与任务调度。

- 单步点击间隔默认 **5 秒**，可在设置中调整。
- 开箱、合成、腐蚀、仓库整理任务共用默认 **20 秒**间隔，最低可设为 **3 秒**；已到期任务遇到操作冲突时等待该间隔。
- 普通宝箱和稀有/BOSS 宝箱按各自 CD 定时检查。每轮使用游戏右键批量入口，依次处理普通与污染变体；空箱检查后仍按完整 CD 等待下一轮。概览显示计划时间，冲突排队时显示倒计时。运行日志逐行带时间。
- 自动腐蚀批次间隔可设 **10～120 秒**；当前批次及动画结束后才开始下一批，其他任务共用间隔仍按设置执行。
- 收到结果后继续等待库存与动画稳定；结果未知或服务器拒绝时暂停后续提交。

这些间隔是当前程序的保护设置，并非游戏官方公布的限流阈值。

![合成与统一节奏](docs/images/02-synthesis.png)

### 铭文材料剔除后继续腐蚀

腐蚀设置分别控制铭文卷轴和纪念币排除。助手按道具名称识别这两类物品，逐件退回；雕刻材料、其他材料和装备保留参与腐蚀。填充会依次选择装备和材料类别，用第二类补充空位，腐蚀允许剩余 **1～9 件**；普通合成仍要求 9 件。

本机运行日志已观察到剔除后剩余 7 件、4 件的批次，均收到成功回包。此记录对应当前游戏版本，后续游戏更新仍需重新核对接口。

![瘟疫与腐蚀设置](docs/images/03-corrosion.png)

### 仓库图片与市场参考价

重复道具合并显示，按品质着色，支持名称搜索、品质 / 类型筛选与价格排序。页面展示已报价道具的参考总值和报价时间。

报价取自 [TBHIndex](https://tbhindex.com/stash) 的 Steam 市场参考数据，并按公开汇率换算成人民币。未知报价单独标记，价格缓存约 30 分钟。参考估值不等于可提现金额，程序不执行市场挂单或交易。

![仓库图片与估值](docs/images/04-warehouse.png)

### 掉落统计

按游戏原生日志周期读取新增宝箱与掉落，页面提供手动刷新。品质汇总排除灵魂石和首领门票，数量与比例随已记录数据计算。“出货啦”合并重复物品并显示数量。

掉落和日志保留范围为 1 小时～30 天，其他记录可设为 1 小时起或永久保存。品质比例描述已记录样本，并非游戏官方掉率。

## 安装与部署

环境：Windows 10/11 64 位、Steam 版 TaskBarHero。下载包自带 Java 17 运行库与官方 BepInEx IL2CPP 后台环境，不需要另外安装。

首次安装：

1. 从 [Releases](https://github.com/buguniaoOVO/TBHHelper/releases/tag/v1.3.63) 下载 Windows x64 ZIP，完整解压到任意可写目录。
2. 双击文件夹里的 `TBH助手.exe` 打开助手，界面显示当前版本。
3. **先退出游戏**，启动助手。助手按已保存路径、运行中的游戏和 Steam 库识别目录，并自动同步当前包的 DLL；无法识别时，在设置页填写游戏目录。
4. 自动初始化会核验 DLL；缺少运行环境时部署附带的环境。设置页“一键部署”可以重新执行完整文件校验。
5. **从 Steam 重新启动游戏**，等助手顶部显示“游戏已连接”。该状态表示助手已收到本地插件 API 的有效响应；首次部署必须重启游戏，插件才会加载。
6. 检查“合成”“瘟疫之地”等页面的规则，再点“一键开启”。开箱与仓库整理随总任务运行；合成、腐蚀与自动前往地图按各自开关执行。F8 或“全部关闭”停止。

首次启动游戏需要生成接口程序集，请给它留出初始化时间。新包的合成、腐蚀和自动前往地图默认关闭，包含仓库默认关闭，铭文卷轴与纪念币排除默认开启。

若助手显示“插件需更新”，退出游戏后助手会自动同步 DLL，随后重新启动游戏。概览和设置页显示实际 API 地址；默认端口 19090 被占用时，插件会选择其他可用端口并通知助手。

## 更新

助手内有两种方式：

- “设置/setting”页点“检测更新”。助手读取 GitHub 最新发布并与当前版本比较；有新版本时询问是否下载。确认后自动下载，在助手退出时替换程序并重新启动。
- “设置/setting”页点“打开发布页”，在浏览器查看完整更新说明与下载包。

助手启动后自动检测 GitHub 最新发布，随后每隔 6 小时检测一次。发现新版本时，顶部显示更新入口，并通过托盘消息提醒；同一版本在本次运行中提醒一次。点击更新入口后可确认下载和安装，自动检测失败会记录到日志，设置页显示最近检测状态。

自动更新和手动换版都在同一个安装目录内进行，一般在 `D:/Tool/赛博养蛊/` 下按版本号建立新目录。更新只替换程序、插件和运行文件，设置、掉落与统计记录、游戏目录、缓存会先备份再恢复，继续沿用原有数据。

首页底部红字免责说明提供官方发布页、QQ群与自愿赞助入口；上方链接栏使用 GitHub、QQ 聊天框和爱心图标。本助手免费下载和使用，Awan维护代码在 GitHub 开源。QQ群：123777707，验证答案：挂机助手。

### 防掉线与立即执行

设置页可开启“防掉线”，按分钟检查游戏与插件连接，异常时结束游戏进程并通过 Steam 重启，页面显示重启次数和最近状态。该功能默认关闭；开启后助手启动时会尝试获取管理员权限，被拒绝时以普通权限运行并用红字说明。

点击“一键开启”后立即执行一轮：地图检测、腐蚀、仓库整理、开箱依次运行，再转入按 CD 的定时调度。

顶部连接区域显示 DLL 初始化状态：黄色表示正在初始化或等待同步，完成后等待游戏连接；实际加载的 DLL 和接口通过校验后显示“游戏已连接”，并隐藏初始化提示。

手工更新：退出游戏和助手，解压新版覆盖旧目录。保留自己的 `settings.properties`、`game-path.txt`、`activity.tsv`、`stats.properties` 与缓存。启动新版助手后会自动核验并同步插件；同步完成后重启游戏即可生效。

助手会检查游戏进程所加载的插件协议与 SHA256。显示“插件需更新”时，先退出游戏，等待助手自动同步完成，再重启游戏。

## 当前范围

这是第三方维护工具，适配依赖游戏版本。请按游戏与平台规则使用。游戏更新后如果接口、地图或库存读取异常，请用 F8 暂停并反馈版本、现象及相关日志。

- 历史日志缺少地图、来源或完整数量时，记录可能显示未知或与当前库存不同。
- 旧版灵魂石历史记录尚未重建；品质汇总已排除该类道具。
- 本次发布经过编译、发布包审计和部署关键文件校验；跨电脑首次启动仍需按快速上手检查游戏插件日志。
- 截图来自本机实际运行，物品、数量、价格随存档和市场变化。

## 源码与构建

Java 助手位于 `src/java`，C# 插件位于 `src/plugin`，独立进程启动器位于 `src/launcher`。构建保留既有 `com.lulu` 命名空间，并以公开包 JAR 作为依赖基线。详细命令见 [构建说明](docs/BUILD.md)。

本仓库不包含游戏本体、生成的 interop DLL、个人配置、统计数据库或完整游戏日志。代码与依赖的来源及许可范围见 [NOTICE](NOTICE.md)。
